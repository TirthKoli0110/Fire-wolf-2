Part 2: HTML Links

1. Hyperlink

Used to connect one webpage to another.

        <a href="https://example.com">
        Visit
        </a>
Visit
  • <a> → Anchor Tag
  • href → Destination URL

2. href Attribute

Specifies the URL (destination) of the hyperlink.

        <a href="https://google.com">
        Google
        </a>
Google

3. target Attribute

Value Meaning
_self Same tab (Default)
_blank Opens in a New Tab
_parent Parent Frame
_top Full Window

Example

        <a href="https://google.com"
        target="_blank">
        Google
        </a>
Open Google in New Tab

4. Absolute URL vs Relative URL

Absolute URL Relative URL
Full Web Address File Path
External Website Internal Page
https://google.com about.html

5. Image as a Link

        <a href="home.html">

        <img src="home.png">

        </a>

6. Email Link

        <a href="mailto:test@example.com">
        Send Email
        </a>
Send Email

7. Button Link

   
        <button
        onclick="location.href='home.html'">
        Home
        </button>

8. title Attribute

The title attribute displays a tooltip when the mouse pointer is placed over a link.

        <a href="page.html"
        title="Go to Page">
        Visit
        </a>
Hover over this link
