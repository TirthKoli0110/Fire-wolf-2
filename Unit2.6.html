5. <blockquote>

Purpose: Displays a long quotation.

        <blockquote cite="https://example.com">
        This is a quotation.
        </blockquote>
This is a quotation. It is displayed as a separate block and is automatically indented by the browser.

Features

  • Block-level element
  • Browser indents the text
  • cite stores the source URL

Remember: Big Quote 📖

6. <q>

Purpose: Displays a short quotation.

        <p>He said <q>Hello</q></p>

He said Hello.

The browser automatically adds quotation marks.

<q> vs <blockquote>

<q> <blockquote>
Short quote Long quote
Inline Block-level
Inside sentence Separate block
Adds quotation marks Indents text

Remember: Q = Quick Quote

7. <abbr>

Purpose: Defines an abbreviation.

        <abbr title="World Health Organization">
        WHO
        </abbr>

WHO

Examples

  • HTML
  • CSS
  • WHO
  • ATM
  • ASAP

Note: Hover the mouse over the abbreviation to see its full form.

8. <address>

Purpose: Displays contact information.

        <address>
        Written by John Doe<br>
        Example.com
        </address>
Written by John Doe
Example.com
Email: john@example.com
Phone: +91 9876543210

Can include:

  • Address
  • Email
  • Website
  • Phone Number
  • Social Media

9. <cite>

Purpose: Specifies the title of a creative work.

        <p>       
        <cite>The Scream</cite>
        by Edvard Munch
        </p>

The Scream by Edvard Munch

Can be used for:

  • ✅ Book
  • ✅ Movie
  • ✅ Song
  • ✅ Painting
  • ❌ Person's Name

10. <bdo>

Full Form: Bi-Directional Override

Purpose: Changes the direction of text.

        <bdo dir="rtl">
        Hello
        </bdo>

Example

Normal Text: Hello

RTL Text: Hello

LTR Text: Hello

Values

Value Meaning
rtl Right → Left
ltr Left → Right

Used for Languages

  • Arabic
  • Hebrew
  • Persian
