  • Text Color
  • Border Color

RGB Color Model

RGB = Red + Green + Blue

        rgb(red, green, blue)
Color RGB Value Output
Red rgb(255,0,0) Red
Green rgb(0,255,0) Green
Blue rgb(0,0,255) Blue
Black rgb(0,0,0) Black
White rgb(255,255,255) White
Gray rgb(120,120,120) Gray

RGBA

RGBA = RGB + Alpha

        rgba(255,0,0,0.5)

RGBA Example (50% Transparent)

Alpha Meaning
0 Transparent
0.5 50% Visible
1 Fully Visible

HEX Colors

        #RRGGBB
Color HEX Code Output
Red #FF0000 Red
Green #00FF00 Green
Blue #0000FF Blue
White #FFFFFF White
Black #000000 Black

HSL

HSL = Hue + Saturation + Lightness

        hsl(0,100%,50%)
Property Description
Hue 0° = Red, 120° = Green, 240° = Blue
Saturation 100% = Pure Color, 0% = Gray
Lightness 0% = Black, 50% = Normal, 100% = White
