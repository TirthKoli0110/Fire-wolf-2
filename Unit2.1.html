1. What is HTML?

  • HTML = HyperText Markup Language
  • Standard markup language used to create web pages.
  • Describes the structure of a webpage.
  • Uses tags to display content.

Examples of Tags

Heading

This is a paragraph.

Visit Google

2. Basic HTML Structure

Explanation

Tag Purpose
<!DOCTYPE html> Declares HTML5 document
<html> Root element
<head> Stores page information
<title> Browser tab title
<body> Visible webpage content

3. HTML Elements

An HTML element consists of:

Start Tag + Content + End Tag

Example

  • <p> → Start tag
  • Hello World → Content
  • </p> → End tag

Empty Element

This is the first line.
This is the second line after a line break.

4. Web Browser

A browser reads HTML code and displays it as a webpage.

Examples

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

Note: The browser displays the webpage, not the HTML tags.
