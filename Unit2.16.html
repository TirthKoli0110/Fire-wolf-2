📌 Quick Formula

RGB   = Red + Green + Blue
RGBA  = RGB + Alpha
HEX   = #RRGGBB
HSL   = Hue + Saturation + Lightness
URL   = href
Image = src + alt
List  = ul / ol / dl
Table = table + tr + th + td
Form  = form + label + input
Choice = Radio (One) | Checkbox (Many)
Semantic = header, nav, main, section, article, aside, footer
Drag & Drop = draggable → ondragstart → ondragover → ondrop
