HTML Lists, Tables, Images & Forms

1. Relative URL

Definition: A Relative URL links to files within the same website.

Examples

<a href="index.html">Home</a>
Home

<a href="pages/about.html">About</a>
About

<a href="../index.html">Home</a>
Parent Folder

Relative URL vs Absolute URL

Relative URL Absolute URL
Internal Link External Link
No Domain Name Complete Web Address
about.html https://example.com/about.html
