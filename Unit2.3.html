15. HTML is Not Case Sensitive

Both of the following examples work:

Uppercase Tags

        <P>Hello</P>

Lowercase Tags

        <p>Hello</p>

Recommendation: Always use lowercase HTML tags.

16. HTML Attributes

Attributes provide extra information about HTML elements.

Syntax

        <tag attribute="value">

Example

        <a href="https://example.com">
        Visit
        </a>
Visit

17. Important Attributes

1. href

Specifies the destination of a hyperlink.

        <a href="https://example.com">
        Visit
        </a>
Visit Example

2. src

Specifies the location of an image.

        <img src="image.jpg">

URL Types

  • Absolute URL → Points to an external website.
  • Relative URL → Points to a file within the same website.

3. width & height

Sets the image size.

        <img src="image.jpg"
        width="300"
        height="400">

4. alt

Displays alternative text if the image cannot be loaded and improves accessibility.

        <img src="image.jpg"
        alt="Nature">

5. style

The style attribute is used for inline CSS.

        <p style="color:red;">
        Hello
        </p>

Hello

Used For

  • Text Color
  • Font
  • Font Size
  • Margin

6. lang

Specifies the language of the webpage.

        <html lang="en">

Example

        <html lang="en-US">

7. title

The title attribute displays a tooltip when the mouse pointer is placed over an element.

        <p title="Information">
        Hover me
        </p>

Hover your mouse over this text.
