1. <sub> - Subscript

Purpose: Displays text below the normal line.

Syntax

        H<sub>2</sub>O

Output

H2O

Uses

  • Chemical formulas (H2O, CO2)
  • Mathematical notation

Remember: Sub = Down ⬇️

2. <sup> - Superscript

Purpose: Displays text above the normal line.

Syntax

        x<sup>2</sup>

Output

x2

Uses

  • Powers (x2)
  • Footnotes
  • Ordinal numbers (1st, 2nd)

Remember: Sup = Up ⬆️
